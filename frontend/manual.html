📖 HOW TO USE

🎮 What Is This?

BGMI Live Scoreboard is a tournament scoring system for BGMI/PUBG esports events. It uses OBS Virtual Camera + live OCR to automatically detect kill-feed events from a game stream, then updates a live scoreboard overlay in real time that you can add as a browser source in OBS.

✅ Prerequisites

  • 1
    OBS Studio — Download from obsproject.com. You need it to capture the game feed and expose it as a Virtual Camera.
  • 2
    Python 3.10+ + uv package manager installed. Dependencies are already in pyproject.toml.
  • 3
    BGMI / PUBG game running on the same machine (or a capture card if streaming from a phone/console).

🚀 Step-by-Step Setup

Step 1 — Configure OBS

  • A
    Open OBS Studio. Add a Game Capture or Window Capture source pointing to the game window.
  • B
    Click Start Virtual Camera in OBS (bottom-right). This makes the game feed available as a webcam to other applications.
  • C
    Optionally, add a Video Capture Device scene for the game feed — but keep Virtual Camera running throughout the match.
⚠️ Make sure the game is visible in OBS before starting Virtual Camera. The kill-feed zone must be clearly visible and not cropped.

Step 2 — Enter Teams & Players (this page)

  • 1
    Go to the Setup tab. Add each competing team with its name, color, and players.
  • 2
    For each player enter: PlayerName (alias1, alias2) — aliases are the in-game names OCR will look for in the kill-feed.
  • 3
    Fill in tournament settings (title, map, total matches). Click Save Tournament Settings.

Step 3 — Start the Backend Server

  • 1
    Open a terminal in the project root and run:
    uv run uvicorn backend.main:app --port 8000
  • 2
    The browser will auto-open to the Setup page. If not, navigate to http://127.0.0.1:8000/frontend/setup.html

Step 4 — Start the OCR Pipeline

  • 1
    In a second terminal, run:
    uv run python main.py --live
  • 2
    The pipeline will connect to OBS Virtual Camera (device index 0 or 1) and start reading kill-feed frames.
  • 3
    When a kill event is detected, it is automatically posted to the API and broadcast to all connected clients.
ℹ️ If OBS Virtual Camera is not detected at index 0, try: uv run python main.py --live --camera-index 1

Step 5 — Add Overlays in OBS

  • 1
    In OBS, add a Browser Source for each overlay you want.
  • 2
    Go to the Output tab in this UI for the exact URLs to paste.
  • 3
    Recommended overlay sizes: Scoreboard 1280×720, MVP 400×220, Top Fraggers 380×340.

⏱️ Match Lifecycle

Use the control bar at the top of the Live page to manage match state:

  • ●
    LIVE COUNTING — OCR and operator kills are accepted and broadcast instantly.
  • ⏸
    PAUSED — Kill registration is blocked. Use during circle transitions or halftime. Toggle with Pause / Resume Counting.
  • 🏁
    FINISHED — Match is locked. Placement points are assigned based on elimination order and saved to history automatically. Click Next Match to start a new round.
⚠️ Placement points follow BGIS rules: 1st = 12pts, 2nd = 9pts, 3rd = 8pts … Click End & Lock Match when the match winner is determined.

💡 Operator Tips

  • 👆
    Manual kill entry: click a team row in the Live tab to select it, then click the + button on the right-side operator panel, or use the kill select buttons.
  • ↩
    Undo last kill: if OCR or an operator makes a mistake, click Undo Last Kill in the table footer immediately.
  • ❌
    Eliminate a team: select the team row and click Team Eliminated. Placement points are NOT assigned until End & Lock Match.
  • 🔄
    Reset current match: zeroes all kills for this match without advancing the match number. Use only to fix a data entry disaster.
  • 📥
    History CSV: go to History → click Download CSV to export overall standings for publishing or as a spreadsheet backup.

🔧 Troubleshooting

  • ?
    OCR detects 0 kills — Make sure OBS Virtual Camera is running and the game's kill-feed is in the top-right area of the frame. If the kill-feed looks different in this game version, re-run with --no-ocr and score manually.
  • ?
    WebSocket not connecting — Check that the backend is running (uv run uvicorn backend.main:app --port 8000). Look for red error badges in the status strip.
  • ?
    Wrong team names detected — Update player aliases in the Setup tab so they match exactly what appears in the in-game kill-feed. Short aliases (6–10 chars) work best.
  • ?
    CORS errors in browser — Always open the frontend through http://127.0.0.1:8000/frontend/, not directly via file:// paths.
  • ?
    Browser didn't auto-open — Navigate manually to http://127.0.0.1:8000/frontend/setup.html.
